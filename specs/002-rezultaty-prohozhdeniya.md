# 002. Результаты прохождения набора

Статус: команда «делай» получена, функция реализована. Автоматические проверки пройдены; визуальная проверка в браузере остаётся непроверенной.

## Для кого и зачем

Для детей, изучающих русский, английский и казахский языки: после прохождения набора увидеть, сколько переводов удалось выбрать с первой попытки и сколько ошибок было допущено.

## Что должно быть

- На существующем экране завершения набора показывать две строки:
  - «Верно с первой попытки: X из 20»;
  - «Ошибок: Y».
- Набор содержит 10 слов. Перевод каждого слова на каждый из двух остальных языков — отдельное задание; всего 20 заданий.
- Каждый выбранный неправильный ответ увеличивает Y на 1, включая повторные ошибки в одном задании.
- Задание увеличивает X на 1 только после правильного ответа и только если в этом задании не было ни одной ошибки.
- Ошибки в одном переводе слова не влияют на зачёт первого ответа в переводе того же слова на другой язык.
- Нажатие «Повторить», переворот карточки и переход к следующему слову сами по себе не меняют счётчики.
- При каждом начале нового прохождения обнулять счётчики и сведения об ошибках в заданиях: при повторе завершённого набора, выборе любой рубрики, в том числе прежней после возврата, и запуске набора после обновления страницы.
- Результаты и сведения об ошибках хранить только в памяти текущего прохождения. После обновления страницы прежние результаты не восстанавливаются. Существующее сохранение последней выбранной рубрики остаётся.

## Примеры

- Все 20 переводов выбраны сразу правильно: «Верно с первой попытки: 20 из 20», «Ошибок: 0».
- Четыре неправильных ответа в трёх разных заданиях: «Верно с первой попытки: 17 из 20», «Ошибок: 4».
- Четыре ошибки в одном задании, остальные выполнены сразу правильно: «Верно с первой попытки: 19 из 20», «Ошибок: 4».
- В первом переводе одного слова допущена ошибка, второй выбран сразу правильно; все остальные переводы без ошибок: «Верно с первой попытки: 19 из 20», «Ошибок: 1».
- В каждом задании была хотя бы одна ошибка: «Верно с первой попытки: 0 из 20»; число ошибок может превышать 20.
- После прохождения с ошибками начато новое и выполнено без ошибок: «Верно с первой попытки: 20 из 20», «Ошибок: 0».

## Ограничения

- Только локальные HTML, CSS и JavaScript, без npm, библиотек, внешних ресурсов и сетевых запросов.
- Не сохранять результаты в localStorage или другом постоянном хранилище.
- Не менять существующие правила выбора языков, случайного порядка слов и переводов, повторных попыток, переворота карточки и перехода после двух правильных переводов.
- Интерфейс на русском языке. На ширине 375px обе строки полностью читаются без горизонтальной прокрутки; существующие кнопки остаются не меньше 44 × 44px.
- Казахские буквы и IPA отображаются без искажений.
- Реализацию начинать только после команды «делай». После реализации обновить README.md с описанием результатов и шагами проверки. Не выполнять git add и git commit.

## Готово, когда

1. На экране завершения после 10 слов показаны обе строки в указанном формате с общим количеством 20 заданий.
2. Прохождение без ошибок даёт 20 из 20 и 0 ошибок.
3. Четыре ошибки в трёх заданиях дают 17 из 20 и 4 ошибки.
4. Повторные ошибки одного задания увеличивают только число ошибок; задание не засчитывается с первой попытки после исправления ответа.
5. Два перевода одного слова учитываются независимо, для каждого из трёх возможных исходных языков.
6. Повтор набора и выбор рубрики после частичного или полного прохождения начинают подсчёт заново.
7. F5 во время прохождения и на экране завершения не восстанавливает результаты; выбранная рубрика сохраняется по существующим правилам. Завершение нового прохождения без ошибок после F5 даёт 20 из 20 и 0 ошибок.
8. Открытие index.html двойным щелчком, выбор ответа, переворот с правильным переводом и повтор ошибочного задания работают как раньше.
9. На ширине 375px результаты читаются полностью, нет горизонтальной прокрутки, кнопки соответствуют минимальному размеру; казахские буквы и IPA не искажены.
10. README.md обновлён после реализации; в отчёте указаны изменённые файлы, выполненные проверки и оставшиеся непроверенными пункты.
