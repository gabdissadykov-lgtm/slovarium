# 015. Прогресс ребёнка за месяц и семейная доска славы

Статус: спецификация для согласования. Реализация — после команды «делай».

## Для кого и зачем

Для родителя, который хочет увидеть итоги занятий ребёнка за месяц, выделить три самых хорошо освоенных модуля и поделиться коротким отчётом с близкими или преподавателем через мессенджер. Если детей несколько — собрать семейную доску славы с карточками детей и местами за месяц.

## Что должно быть

### Открытие и период

- В кабинете родителя у выбранного ребёнка кнопка «Прогресс за месяц».
- По умолчанию открыт текущий календарный месяц; можно выбрать предыдущие месяцы, за которые есть история. Текущий месяц подписан «Месяц ещё идёт».
- Границы месяца считаются по времени Казахстана (Asia/Aqtau, UTC+5), одинаково на всех устройствах. Учитываются события с начала первого дня включительно до начала следующего месяца исключительно.
- Отчёт показывает имя ребёнка, месяц, число дней с завершёнными занятиями, число завершённых прохождений карточек и предложений отдельно, число разных пройденных уроков для каждого уровня и число впервые полученных учебных наград за слова и предложения отдельно.
- Повторное прохождение входит в число занятий, но не увеличивает число разных уроков или впервые полученных наград. Незавершённое занятие не считается завершённым.
- Очные проверки 014 показываются отдельным числом завершённых проверок за месяц. Они не входят в рейтинг самостоятельного освоения и не меняют награды.

### Три самых освоенных модуля

- Блок «Лучше всего освоены» показывает до трёх модулей, по которым в выбранном месяце завершено хотя бы одно самостоятельное занятие.
- Для рейтинга используются результаты только выбранного месяца. Для каждой пары «урок + уровень» берётся лучшее завершённое прохождение этого месяца.
- Для карточек результат — доля переводов, выполненных с первой попытки (из 18 или 20); для предложений — доля заданий, полностью выполненных без ошибки на обоих этапах (из 9 или 10). Если текущие данные не содержат последнюю метрику, её начинают сохранять при реализации, без восстановления по догадке.
- Освоение модуля = число таких успешных ответов в лучших прохождениях / полное число возможных ответов всех уроков обоих уровней модуля × 100%. Непройденные уроки и уровни дают нулевой вклад. Рядом показывается охват: сколько пар «урок + уровень» пройдено из общего количества.
- Так учитываются и точность, и полнота освоения; разный размер модулей нормируется. Подпись поясняет: «По результатам занятий за выбранный месяц».
- Сортировка по неокруглённому проценту освоения по убыванию, затем по доле пройденных пар, затем по номеру модуля. На экране проценты округляются до целых.
- При одном или двух изученных модулях показываются только они. При отсутствии занятий — «За этот месяц пока нет завершённых занятий», без вымышленных лидеров.
- Это учебный показатель приложения, а не подтверждение свободного владения языком. Сравнение детей допускается только внутри своей семьи в отдельной доске славы; общего рейтинга семей нет.

### Семейная доска славы

- Рейтинг среди детей ведётся за каждый календарный день, отдельно от индивидуального месячного отчёта. Границы дня — 00:00–24:00 по Asia/Aqtau (UTC+5). По умолчанию открыто «Сегодня»; можно выбрать предыдущий день с историей.
- В кабинете родителя действие «Доска славы». Родитель выбирает участвующих детей своей семьи; по умолчанию включены все существующие профили. При одном участнике показана персональная карточка достижений без соревновательного места.
- На общей карточке заголовок «Наша доска славы», дата и карточки выбранных детей: имя, место и число успешно пройденных за день модулей. На телефоне карточки располагаются вертикально. Месячные итоги и три лучших модуля остаются в отдельном отчёте ребёнка.
- Уточнение для реализации: модуль — целая тема из каталога, состоящая из нескольких уроков, а не один урок. Успешное прохождение модуля фиксируется, когда для всех его уроков подтверждены карточки с результатом не ниже 80% (16/20 или 15/18) и завершён уровень предложений. Результаты могут накапливаться в разные дни; модуль засчитывается в день подтверждённого завершения последнего недостающего условия. Если прежних данных недостаточно для подтверждения условий, успех не восстанавливается по догадке.
- Места присваиваются автоматически по числу разных успешно завершённых модулей за выбранный день, по убыванию. Один модуль засчитывается ребёнку один раз; повторное прохождение уже освоенного модуля не создаёт новый успех. Повторные отправки и параллельные вкладки не увеличивают счётчик.
- При одинаковом числе модулей дети делят место: 1, 1, 3. Порядок карточек с общим местом — по имени, затем стабильному ID профиля, без изменения места. Возраст, баланс монет, обмены и оценки очной проверки не влияют на рейтинг.
- Дети без успешно завершённых модулей за день показаны с подписью «Пока нет завершённых модулей» без места. Если результат есть только у одного из нескольких участников, он получает первое место. При отсутствии результатов места не назначаются.
- После каждого подтверждённого успешного завершения очередного модуля рейтинг автоматически пересчитывается у родителя во всех открытых онлайн-сеансах, без F5. Клик или локальная очередь не считаются подтверждённым результатом. После восстановления связи сначала загружаются подтверждённые данные, затем обновляются места.
- В полночь открытая доска «Сегодня» переключается на новый день и начинает дневной счёт заново; предыдущие результаты остаются в истории. Освоенные модули не становятся непройденными. После возврата к вкладке дата также сверяется. Отложенная синхронизация относит успех к дню завершения на устройстве по правилам истории, а не к дню отправки; соответствующая прошлая доска пересчитывается.
- При ошибке загрузки хотя бы одного выбранного профиля места не рассчитываются до успешной загрузки. Кеш и неполная история явно помечаются, дата начала истории видна. Рейтинг описывает сохранённые результаты, а не способности, возраст или усилия ребёнка.
- Родитель может менять состав участников, но не назначать места вручную. После изменения состава места пересчитываются. Доска не начисляет наград и не меняет учебные результаты.
- Доска доступна только родителю своей семьи; детский интерфейс не получает историю братьев и сестёр. Удалённые профили не отображаются.
- Родитель может скопировать общий текст либо сохранить общую карточку картинкой PNG и передать её через системное меню, если поддерживается отправка файлов. Если отправка картинки недоступна, предлагаются «Скачать карточку» и копирование текста. Картинка формируется локально средствами браузера, без стороннего сервиса.
- Перед сохранением и отправкой показан предпросмотр. Можно скрыть имена, заменив их на «Участник 1», «Участник 2» в порядке выбора, одинаково в тексте и картинке. В выгрузку входят только выбранные дети, дата, места, число завершённых модулей и необходимые пометки о полноте данных. Личные и технические идентификаторы не выводятся. Выгрузка соответствует показанному состоянию доски на момент нажатия.

### Копирование и отправка

- Под отчётом доступен предварительный просмотр короткого текста, совпадающего с тем, что будет скопировано или передано.
- «Скопировать» копирует текст; сообщение «Скопировано» появляется только после успеха. Если буфер обмена недоступен, отображается выделяемый текст и инструкция скопировать вручную.
- «Поделиться» по нажатию родителя открывает системное меню отправки там, где оно поддерживается. Родитель сам выбирает мессенджер, адресата и подтверждает отправку. При отсутствии поддержки предлагается копирование. Отмена меню не считается успешной отправкой или ошибкой отчёта.
- В индивидуальном отчёте передаются только имя ребёнка, месяц, сводные показатели и до трёх модулей с процентами и охватом. При неполной истории передаётся также предупреждение об этом. Родитель может выключить имя; тогда используется «Ребёнок».
- Телефон, почта, семейные идентификаторы, коды привязки, внутренние ссылки и подробные ответы в текст не попадают. Публичная страница отчёта не создаётся. Приложение не подключается к аккаунтам мессенджеров и не отправляет сообщения автоматически.

### История и достоверность

- Сохраняется отдельная история завершённых прохождений: стабильный ID попытки, ребёнок, модуль, урок, уровень, числитель и знаменатель результата, время завершения. Повторы отправки одной попытки не создают новое занятие; настоящие повторные прохождения имеют новые ID.
- История дополняет существующие лучшие результаты и награды. Обычный повтор, в том числе с худшим результатом, должен попадать в историю.
- В онлайн-режиме источником отчёта являются подтверждённые данные Firestore. Несохранённые занятия не выдаются за облачные; при наличии очереди показывается, что часть результатов ещё синхронизируется.
- Для отложенной отправки сохраняются время завершения на устройстве и время серверного подтверждения. Месяц определяется по времени завершения; после подтверждения событие не переносится в месяц синхронизации. Неверные часы устройства могут влиять на период, отчёт не является защищённым журналом посещаемости.
- Дата начала ведения истории видна. Если история начата посреди месяца, отчёт и текст помечены «Данные с …». Старые лучшие результаты и перенесённый локальный баланс не превращаются в занятия текущего месяца. Исторические награды без достоверной даты не включаются в месячное начисление.
- При ошибке загрузки не показывать нули как достоверный итог. При использовании кеша указывать, что данные могут быть неполными; перед отправкой предупреждение входит в текст.
- Полный отчёт доступен родителю только своей семьи. Ребёнок и чужая семья не могут читать закрытую историю или менять её. Сохранение ребёнком собственных результатов ограничивается правилами Firestore, а не ролью из интерфейса.
- Полное удаление ребёнка по 013 очищает новую историю, включая вложенные документы, с возможностью продолжить удаление после сбоя.

## Примеры

- За месяц ребёнок завершил один урок карточек трижды. Отчёт показывает три прохождения и один разный урок; для рейтинга берётся лучший результат. Повторная отправка третьей попытки эти числа не меняет.
- У модуля девять уроков по десять записей: всего 180 переводов карточек и 90 заданий предложений. Один урок карточек выполнен 18/20, остальные не проходились: освоение 18/270 ≈ 7%, охват 1/18. Один точный урок не означает освоение всего модуля.
- Занятие завершено 30 ноября в 23:59 UTC+5, а подтверждено сервером 1 декабря: после синхронизации оно входит в ноябрь.
- Пример текста (условные данные):

  Словариум · ноябрь 2026 · Айжан
  Данные с 10 ноября. Месяц ещё идёт.
  Дней с занятиями: 12.
  Прохождений: карточки — 18, предложения — 9.
  Разных уроков: карточки — 12, предложения — 7.
  Новых наград: слова — 64, предложения — 23.
  Очных проверок: 2.
  Лучше всего освоены по занятиям за месяц:
  1. Home & Away — 72%, пройдено 16/18 уровней уроков.
  2. Living Things — 54%, пройдено 14/20.
  3. Values — 38%, пройдено 10/20.

- Изучены только два модуля — в тексте две строки. Отправка отменена — отчёт остаётся открыт, сообщение «Отправлено» не появляется.

- Сегодня Айжан завершила два разных модуля, Аслан и Дана — по одному: места 1, 2, 2. После успешного завершения Асланом второго модуля доска автоматически показывает места 1, 1, 3. Повтор уже освоенного модуля счёт не увеличивает.
- Родитель выбирает троих детей, скрывает имена и сохраняет общую PNG-карточку: в ней только «Участник 1–3», дата, результаты и места.

## Ограничения

- Первая версия: календарный месяц, самостоятельные карточки и предложения, отдельное число очных проверок, текстовое копирование и системная отправка. Дополнительно — ежедневная семейная доска славы, общий текст и PNG-карточка. Графики, PDF, автоматические рассылки и сравнение с предыдущим месяцем не входят в задачу.
- HTML/CSS/JavaScript без обязательной сборки, действующие Firebase и Netlify. Без новых библиотек, аналитики, платных услуг и банковской карты. История загружается по выбранному периоду; при необходимости индексы описываются в документации. До реализации оценить чтения, записи и хранение в бесплатных лимитах.
- Первая версия отчёта — в онлайн-кабинете родителя по HTTPS. Локальное обучение через двойной щелчок сохраняется; локальные данные автоматически в отчёт не переносятся.
- Русский интерфейс, кнопки от 44 px, отсутствие горизонтального переполнения при 375 px, корректные казахские буквы в отчёте и скопированном тексте.
- Не менять механику обучения, начисление наград и обмен. В предложениях сохраняются квоты 8 казахских/2 русских для 10 заданий и 7/2 для 9. Коммиты делает пользователь.

## Готово, когда

- [ ] Родитель выбирает ребёнка и месяц; показатели совпадают с датированной историей, разные дети и месяцы не смешиваются.
- [ ] Проверены границы месяца и года, февраль, текущий неполный месяц, начало истории посреди месяца, отсутствие данных и отложенная синхронизация.
- [ ] Повторы, худшие результаты, двойные клики и две вкладки учитываются правильно; незавершённые занятия не попадают в итог. F5 и повторный вход сохраняют отчёт.
- [ ] На примерах модулей разных размеров проверены формула, оба уровня, 9/10 заданий, равенства рейтинга и случаи 0/1/2/3 и более изученных модулей.
- [ ] Старые результаты без истории не приписываются месяцу; ошибки загрузки и очередь не маскируются достоверными нулями.
- [ ] Копирование, ручной запасной вариант, скрытие имени, системная отправка и её отмена проверены; предварительный просмотр совпадает с переданным текстом.
- [ ] Доска показывает выбранных детей своей семьи; проверены 0/1/несколько участников с завершёнными модулями, равные результаты, разные даты истории, ошибка загрузки и удалённый профиль. Места соответствуют числу модулей и пересчитываются при смене состава, а также автоматически после каждого подтверждённого успеха без F5. Проверены составной модуль из нескольких уроков, пороги 16/20 и 15/18, запрет повторного зачёта, полночь UTC+5, возврат к вкладке и отложенная синхронизация в прошлый день.
- [ ] Проверены предпросмотр общей карточки, PNG без обрезания текста, длинные имена и казахские буквы, скачивание, отправка файла и запасной текстовый вариант. Скрытие имён работает в обоих форматах.
- [ ] Настоящие правила Firestore проверены на доступ родителя, запреты ребёнку и чужой семье, повторные записи; удаление профиля очищает новую историю и продолжается после сбоя.
- [ ] По HTTPS на двух независимых браузерах/устройствах проверены синхронизация, повторный вход и сбой сети. Модельные проверки отделены от живых.
- [ ] Проверены 375 px, элементы от 44 px, казахские буквы, прежние карточки, награды и квоты предложений 8/2 и 7/2.
- [ ] После реализации README обновлён: что умеет отчёт, как считается освоение, с какой даты есть история, как проверить и что осталось непроверенным.
