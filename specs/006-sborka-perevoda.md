# 006. Английские предложения и сборка перевода

Статус: реализовано по команде «делай». Автоматические проверки пройдены; реальные браузерные и независимая языковая проверки остаются непроверенными. Языковое распределение уточнено пользователем: из десяти переводов восемь казахских и два русских.

## Для кого и зачем

Для детей, изучающих английский и казахский с опорой на русский. Сначала понять английское предложение и дополнить его, затем осмысленно собрать перевод, уделяя больше внимания казахскому языку.

## Что должно быть

### Состав и доступ

- Изменение относится ко второму уровню всех доступных тренировок: всех 86 уроков девяти тем модулей 1–9. После 007 старые шесть рубрик из интерфейса убраны; их внутренний архив сохранён. Подключение модулей 2–9 выполнено последующим продолжением 005.
- Первый уровень с карточками, случайными исходными языками и двумя переводами не меняется. Порог доступа к предложениям остаётся не менее 80% переводов с первой попытки: 16/20 для десяти записей, 15/18 для девяти.
- На втором уровне каждое исходное понятие используется ровно один раз: десять двухэтапных заданий для десяти записей. Повтор ошибочного этапа не создаёт новое задание.
- Все предложения с пропуском теперь только на английском. Для каждого прохождения из десяти заданий назначить ровно восемь казахских и два русских перевода. Порядок заданий и распределение языков между ними перемешиваются, в том числе при «Повторить предложения». Язык конкретного задания не меняется при ошибке.
- Для будущих уроков из девяти записей используются семь казахских и два русских перевода; девять исходных предложений английские. Правило принято командой «делай»; в продолжении 005 подключены 31 урок такого размера.
- Новое требование пользователя заменяет прежнее распределение исходных предложений 4/4/2 из AGENTS.md и спецификаций 003–005. Оно не распространяется на карточки. Сам AGENTS.md автоматически не переписывать.

### Этап 1 — дополнить английское предложение

- Показать английское предложение с одним пропуском и три разных английских варианта ответа. Только один подходит по смыслу и грамматике. Многословный ответ допустим.
- Подсказки к видимым английским словам сохраняются по 004. Пропуск и варианты ответа подсказок не имеют; скрытое слово не раскрывается другими подсказками.
- После ошибки действуют прежние правила: показать полное правильное английское предложение и «Повторить», заблокировать переход. Повтор возвращает пропуск; сборка перевода ещё недоступна.
- После правильного ответа оставить полное английское предложение наверху. Под ним сразу открыть этап сборки перевода и подпись «Собери перевод на казахском» или «Собери перевод на русском».
- Английские подсказки работают и после ответа. Во время сборки они могут помогать переводу, но не показывают готовую последовательность слов перевода.

### Этап 2 — собрать перевод

- Показать пустую область ответа и набор перемешанных слов на назначенном языке. Полный перевод в правильном порядке до успешной проверки не показывать.
- Использовать все слова перевода, без лишних слов. Изначальная последовательность должна отличаться от правильной, если слова допускают другой порядок. Перемешивание не меняет состав слов и их формы.
- Нажатие на слово добавляет его в конец собираемого предложения и убирает из доступного набора. Нажатие на уже выбранное слово возвращает именно этот экземпляр в набор. «Очистить» возвращает все слова.
- Одинаковые слова — отдельные экземпляры с собственными идентификаторами. Они могут встречаться несколько раз и не должны теряться или дублироваться. Обмен местами одинаковых экземпляров не делает ответ неправильным.
- Использовать нажатия и клавиатуру; перетаскивание не обязательно. Все словесные кнопки доступны по Tab и активируются Enter/пробелом, размер не меньше 44 × 44 CSS px.
- Кнопка «Проверить» доступна, когда использованы все слова. Неполная сборка не считается ошибкой. Добавление, удаление, очистка и изменение порядка до проверки не меняют счётчики.
- После неправильной полной сборки показать «Попробуй ещё раз», сохранить английский текст и собранную последовательность для исправления. Готовый перевод не раскрывать, не возвращать к выбору английского слова. Следующее задание остаётся закрытым.
- Повторная отправка неизменённого ошибочного ответа не добавляет ошибку повторно: для следующей проверки нужно изменить сборку. После изменения новая неверная проверка считается новой ошибкой.
- После правильной сборки показать «Верно!» и готовый перевод, зафиксировать результат. Только теперь доступно «Следующее предложение»; после последнего задания — итоги.
- Пунктуация не является отдельной перетаскиваемой или выбираемой карточкой. Хранить её оформление отдельно и восстанавливать в собранном тексте. При сравнении не учитывать регистр и оформление знаков препинания; формы слов и порядок учитывать.
- Для русского и казахского допускаются разные естественные порядки слов. Для каждого задания заранее подготовить допустимые последовательности из того же набора слов; не отклонять очевидно естественный вариант только из-за несовпадения с одним эталоном. Проверить задания при подготовке; не использовать автоматическую проверку смысла через интернет.

### Данные и подсказки

- Для всех 60 понятий тематических тренировок и 829 исходных записей всех модулей подготовить английское задание, его полный текст и точные эквивалентные переводы на казахский и русский. Для назначения восьми переводов на казахский случайным понятиям нужны обе версии каждого задания.
- Короткие примеры карточек нельзя автоматически считать переводами задания второго уровня: полные предложения должны совпадать по смыслу, деталям, времени и числу. Словарные повторы Module 1 сохраняют собственные идентификаторы.
- Все английские предложения нового банка покрыть контекстными подсказками до и после заполнения, включая слова, которых не было в старом банке. Отсутствие подсказок или неполные переводы не выдавать за готовый контент.
- Данные, варианты порядка слов, IPA и переводы хранятся локально в script.js. Не добавлять библиотеки, внешние сервисы перевода или загрузку словаря в интернет.

### Результаты, повторы и сохранение

- Считать отдельно первый правильный выбор английского слова и первую успешную проверку сборки перевода. При десяти предложениях всего 20 оцениваемых этапов: 10 дополнений и 10 переводов. Схема принята командой «делай».
- На итогах показать «Английские предложения: X из 10 с первой попытки», «Переводы: Y из 10 с первой попытки» и общее число ошибок. Ошибка на английском этапе не лишает перевод возможности засчитаться с первой проверки, и наоборот.
- Каждая неверная попытка английского выбора и каждая новая неверная полная проверка сборки увеличивает общее число ошибок на один. После ошибки соответствующий этап уже не считается выполненным с первой попытки.
- Для курса лучший результат нового второго уровня сравнивать по сумме X + Y из 20, при равенстве — по меньшему общему числу ошибок. Сохранять также оба отдельных показателя одной завершённой попытки. Неполное прохождение не сохранять как завершённое.
- Статус «Предложения пройдены» в новом формате появляется только после обоих этапов всех заданий.
- Старые лучшие результаты карточек и выбор урока сохраняются. Старые завершённые результаты предложений хранить отдельно как результаты прежнего формата: не сравнивать 10 прежних ответов с 20 новыми этапами и не приписывать старому результату прохождение сборки перевода. Версия результата и состава заданий должна отличать форматы.
- В тематических тренировках результаты по-прежнему временные. В курсе сохраняются только лучшие завершённые результаты; текущая сборка, ответы, язык текущего задания и доступ после карточек не сохраняются.
- F5 начинает карточки выбранного урока/темы заново. Повтор второго уровня в текущем сеансе сбрасывает оба его счётчика, заново перемешивает задания, языки переводов и слова; карточки повторно проходить не требуется.

## Примеры

### Одно задание

1. Английский текст: `Every day, I drink five glasses of ___.` Варианты: `water / bread / cheese`.
2. После выбора `water` наверху остаётся `Every day, I drink five glasses of water.`
3. Если назначен казахский, слова снизу, например: `ішемін · бес · Мен · су · сайын · күн · стақан`.
4. Ребёнок собирает `Мен күн сайын бес стақан су ішемін.` и нажимает «Проверить». При правильной сборке открывается следующее задание.
5. Для того же английского текста русская версия: `Каждый день я выпиваю пять стаканов воды.` Например, исходный набор: `воды · я · пять · Каждый · выпиваю · день · стаканов`. Естественный вариант `Я каждый день выпиваю пять стаканов воды.` также принимается, если используется тот же набор слов.

### Проверяемые сценарии

- За полное прохождение показано 10 английских пропусков, 8 сборок на казахском и 2 на русском. После «Повторить предложения» числа те же; после ошибки язык не меняется.
- Ребёнок ошибся при выборе `water`, исправил выбор и с первой проверки собрал перевод: английский этап не засчитан с первой попытки, перевод засчитан; одна ошибка.
- Английское слово выбрано сразу правильно, две разные полные сборки перевода неверны, третья верна: английский этап засчитан с первой попытки, перевод — нет; две ошибки.
- Перестановки до нажатия «Проверить», «Очистить» и попытка проверить неполный ответ не добавляют ошибок.
- Два одинаковых слова представлены двумя кнопками. Каждая используется не более одного раза; перестановка их идентификаторов при одинаковом тексте не влияет на оценку.
- Все задания выполнены сразу правильно: английские предложения 10/10, переводы 10/10, ошибок 0. Пять ошибочных этапов в разных заданиях не меняют число заданий и языковой состав.
- F5 во время сборки сбрасывает текущую попытку и доступ, сохраняет выбор урока и прежние лучшие завершённые результаты курса. Старый результат формата 003/005 остаётся отдельно и не отмечает новый второй уровень пройденным.

## Ограничения

- Только локальные HTML, CSS, JavaScript; без npm, библиотек и внешних ресурсов. Запуск двойным щелчком без сервера, данные только в браузере.
- Интерфейс и пояснения по-русски, казахские буквы и IPA без искажений. Поддержка 375px, перенос длинных слов, кнопки и словесные области не меньше 44 × 44 CSS px.
- Не менять карточки, каталог, постоянный состав уроков, выделение выбранного режима и порог доступа. Модули 2–9 подключены отдельным запросом в продолжении 005.
- В этой функции переводится каждое предложение на один назначенный язык; сборка обоих переводов одного предложения не требуется.
- Код, README и прежние спецификации на этапе согласования не менять. После реализации обновить README с новым форматом, миграцией результатов и проверками. git add и git commit не выполнять.
