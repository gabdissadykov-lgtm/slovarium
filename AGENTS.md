## Правила
- Приложение остаётся на HTML, CSS и JavaScript без обязательной npm-сборки. Разрешены конфигурации Netlify/Firebase, правила Firestore и документация развёртывания.
- Разрешены Netlify для HTTPS-хостинга, Firebase Authentication для входа и Cloud Firestore для семейных профилей, прогресса, наград и истории обменов. Разрешён официальный Firebase Web SDK; фиксировать версию. Прочие внешние библиотеки, ресурсы и сервисы подключать только по отдельному запросу.
- До реализации 009 текущий режим остаётся локальным. В онлайн-режиме Firestore — источник сохранённых семейных данных; localStorage используется только для локального режима, кеша и подготовки переноса. Не считать локальную запись подтверждением облачного сохранения.
- Передавать только необходимые данные для входа и обучения. Не подключать рекламу и аналитику. Не хранить пароли, приватные ключи, service account JSON и токены в репозитории, клиентском коде или логах. Публичная конфигурация Firebase Web не является секретом; доступ защищают Authentication и правила Firestore.
- Семьи изолированы правилами Firestore. Ребёнок имеет доступ только к разрешённым данным своего профиля; обмен и управление семьёй доступны родителю. Запрещены открытые правила чтения/записи и доверие к роли, переданной только интерфейсом.
- Награды уникальны по профилю и стабильному идентификатору задания. Обмен и начисления выполняются согласованно, без двойной оплаты и потери параллельных изменений. Не загружать локальный баланс поверх облачного. Перенос старых данных — с выбором ребёнка, подтверждением родителя и защитой от повторного импорта.
- Настраивать без подключения платного тарифа, платных услуг или банковской карты. Если выбранная возможность требует оплаты, подготовить альтернативу или отдельно согласовать расходы. Не удалять и не перенастраивать посторонние проекты пользователя.
- Интерфейс на русском языке, подписи короткие и понятные.
- Кнопки и поля не меньше 44px, страница работает на телефоне шириной 375px.
- Делай только то, о чём попросили. Работающие функции не ломай.
- После каждого завершённого обновления спрашивать «Сделать КОММИТ И ПУШ?». Только после ответа пользователя «Да» или «Делай» на этот вопрос агент выполняет git add, git commit и git push согласованных изменений. Без подтверждения не коммитить и не пушить. Это уточнение владельца от 28.11.2026 заменяет прежнее правило о самостоятельных коммитах пользователя.
- пользователю предлагаются карточки со словами на английском, казахском или русском языке. пользователь выбирает и предложенных трех вариантов правильный перевод. каточка переварачивается и показывается правильный вариант. Для каждого исходного слова порядок угадывания переводов на два остальных языка выбирается случайно. Это правило действует для всех трёх исходных языков. слова подаются в рандомном порядке. пока пользователь не выберет перевод слова на двух остальных языках отличном от языка представленного слова следующее задание не открывается. Казахские буквы (ә, ғ, қ, ң, ө, ұ, ү, һ, і) показывай без искажений
- Текущий уровень предложений работает по 006/007: исходные предложения английские, затем сборка казахского или русского перевода. Для 10 заданий — ровно 8 казахских и 2 русских сборки, для 9 — 7 и 2. Порядок перемешивается случайно. Перед завершением работы проверить количества. Прежнее правило 4 английских / 4 казахских / 2 русских относится к старому формату и не восстанавливается при подключении облака. Правило не относится к уровню карточек.

## Как проверить
- Открыть index.html двойным щелчком.
- Для локального режима сохраняется проверка двойным щелчком. Онлайн-вход и синхронизацию проверять по HTTPS-ссылке Netlify; file:// не является проверкой Firebase Authentication.
- пользователь выбирает перевод слова из предложенных вариантов, далее карточка переварачивается и показывается правильный вариант перевода.
- После F5 данные на месте.
- Для онлайн-режима дополнительно проверить два независимых браузера/устройства, выход и повторный вход, изоляцию семей, права ребёнка/родителя, повторные начисления, обмен при параллельной работе и сбой сети. Ограничения сетевых проверок прежних тестов уточнять только для разрешённых Firebase-соединений; остальные проверки обучения сохранять.
