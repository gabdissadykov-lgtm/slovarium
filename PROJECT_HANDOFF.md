## Проект и инфраструктура

Сервис помогает детям изучать русский, английский и казахский. Интерфейс русский, корректное отображение ә, ғ, қ, ң, ө, ұ, ү, һ, і обязательно.

- Каталог: девять модулей, 829 записей, 86 постоянных уроков (55 по 10 записей, 31 по 9). Повторяющиеся написания разных исходных записей сохраняются по разным ID.
- Стек: обычные HTML/CSS/JavaScript, обязательной npm-сборки нет.
- Репозиторий: `https://github.com/gabdissadykov-lgtm/slovarium.git`, рабочая ветка `main`.
- Рабочий сайт: `https://slovarium.netlify.app`.
- Netlify: проект `slovarium`, Project ID `94a8e115-eea7-4dee-9376-445f3413ae9a`; панель `https://app.netlify.com/projects/slovarium/overview`.
- Firebase: проект `slovarium-ee1c4`, база `(default)`, регион `eur3 (Europe)`, бесплатный тариф Spark. Google-вход для родителя, Anonymous для ребёнка.
- Firebase Console: `https://console.firebase.google.com/project/slovarium-ee1c4/firestore`.
- Официальный Firebase Web SDK закреплён на `13.4.0` в `cloud.js`.
- По `file://` работает локальный режим; онлайн-вход проверять по HTTPS. Локальная запись не подтверждает облачное сохранение.
- Не подключать платные тарифы, банковскую карту, рекламу, аналитику и новые внешние сервисы без отдельного запроса владельца. Не изменять чужие проекты.
- Пароли, токены и приватные ключи не хранить в проекте или логах. `firebase-config.js` содержит публичную Firebase Web-конфигурацию, доступ защищают Authentication и правила Firestore.

## Как работать с владельцем

- Каждую новую функцию начинать со следующего свободного `specs/NNN-nazvanie.md`: «Для кого и зачем», «Что должно быть», «Примеры», «Ограничения», «Готово, когда».
- Сначала спецификация; код — после «делай». Уточнение или исправление уже разрешённой функции выполнять в согласованном объёме.
- После реализации обновлять README: что работает, как проверить, что не проверено.
- После каждого законченного обновления спрашивать: **«Сделать КОММИТ И ПУШ?»** Если владелец отвечает «Да» или «Делай» именно на этот вопрос — агент сам выполняет `git add`, `git commit`, `git push` согласованных файлов. Без подтверждения не коммитить и не пушить. Это более позднее указание владельца заменяет старое правило «коммиты делаю сам».
- При необходимости публикации правил спросить о выпуске конкретного готового изменения вместе с коммитом/пушем. Для изменения 017 такое подтверждение уже получено: **«да делай»** на вопрос «Опубликовать правила Firestore и сделать КОММИТ И ПУШ?».
- Затем владелец дополнительно попросил сохранить эту передачу работы в отдельном файле проекта. Эта просьба дополняет текущую публикацию 017, не отменяет её.
- Не удалять реальные детские профили ради тестирования. Использовать демонстрационные данные и локальный эмулятор.
- Сообщать об изменённых файлах, проверках и ограничениях честно: модельный тест не равен живой проверке двух устройств.

## Что уже опубликовано и подтверждено

До текущего этапа реализованы локальное и онлайн-обучение, семейные профили, уникальные награды, обмен, импорт, управление устройствами и очная проверка. Статус ранних этапов уточнять по README и спецификациям.

В этом цикле завершён кабинет родителя (016):

- В кабинете и на главном экране — имя родителя, без детского баланса и учебного меню.
- В открытом профиле ребёнка — имя и баланс именно этого ребёнка. Не закреплять имя родителя на всех экранах: владелец явно исправил такое поведение.
- Логотип «Словариум» ведёт на главный экран.
- Одна форма подключения: имя ребёнка и код устройства. Профиль и привязка создаются атомарно; неверный/занятый код, повтор и потеря подтверждения не оставляют дублей и пустых профилей. Занятое устройство не переносится между детьми молча.
- Компактный список детей. Настройки последнего ребёнка не показываются под списком. Подробности, устройства, импорт, проверка, обмен и удаление находятся на отдельном экране профиля; есть «Назад к детям».
- Смена профиля без reload снимает обработчики старого обучения, закрывает формы/подтверждения и не переносит операции другому ребёнку.
- Удаление только родителю: предупреждение → «Продолжить удаление» → точный ввод имени → «Удалить навсегда». Отмена на обоих шагах; смена ребёнка, выход в кабинет и переименование сбрасывают подтверждение. Возобновление незавершённого удаления также требует подтверждения.
- Владелец отдельно уточнил: **родитель только наблюдает, отслеживает и управляет; не проходит уроки за ребёнка**. Кнопки «Учиться» и учебного меню у родителя нет; переход к уроку блокируется, учебные ответы и награды не записываются. Импорт/обмен/очная проверка остаются родительскими операциями.
