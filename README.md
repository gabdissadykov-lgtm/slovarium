# Слово за словом

Локальное приложение для изучения слов без зависимостей и сборки.

Откройте `index.html` в браузере. Для запуска через сервер: `python3 -m http.server 8000`, затем откройте `http://localhost:8000`.

- Шесть рубрик: Еда, Транспорт, Дом, Школа, Путешествие, Другое.
- В каждой рубрике по 10 слов на английском, русском и казахском языках — 180 карточек.
- На карточке: слово, транскрипция для английского, короткое предложение на выбранном языке.
- Кнопка «Практиковаться» открывает последовательный просмотр примеров с пропущенным словом и раскрытием ответа.

Данные находятся в `data/words.js`, поведение в `app.js`, оформление в `style.css`.
