# Словариум

Карточки для детей, изучающих английский, казахский и русский вместе. Работают локально: откройте `index.html` двойным щелчком. Установка, сборка, сервер и интернет не нужны.

## Возможности

- Шесть рубрик: Еда, Транспорт, Дом, Школа, Путешествие, Другое.
- По 10 разных понятий в каждой: всего 60 понятий и 180 языковых вариантов, без повторов понятий между рубриками.
- Одна карточка с исходным словом и коротким примером на том же языке. Английские слова сопровождаются британской IPA: в задании, подписи, вариантах ответа и правильном переводе на обороте.
- Понятия идут в случайном порядке без повторов внутри прохождения. Язык каждой карточки независимо выбирается из трёх с равной вероятностью.
- Нужно угадать два перевода. Порядок остальных языков случайный для любого исходного языка. На каждом этапе — три разных варианта из той же темы.
- После ответа карточка переворачивается и показывает правильный перевод и результат. После первого правильного ответа сразу открываются три варианта второго перевода под подтверждением первого, без промежуточной кнопки. Ошибка требует кнопки «Повторить» и новой попытки того же этапа. Перейти к следующему слову можно только после двух правильных ответов.
- После десяти понятий можно повторить набор или вернуться к рубрикам. Вернуться к рубрикам можно и в процессе.
- После завершения видны «Верно с первой попытки: X из 20» и «Ошибок: Y». Два перевода каждого из 10 слов — 20 отдельных заданий. Каждая ошибка увеличивает Y; задание входит в X, только если выполнено без ошибок. При новом прохождении и F5 подсчёт начинается заново, результаты не сохраняются.
- Последняя выбранная рубрика выделяется на главной и сохраняется в `localStorage` под ключом `slovarium.category`. После F5 её набор начинается заново. Прогресс и язык карточки не сохраняются.
- Если хранилище недоступно, обучение продолжается без сохранения. Неизвестная сохранённая рубрика игнорируется.

Данные не передаются в интернет. Поддержка постоянного хранения для локальных файлов зависит от браузера и его настроек; при запрете хранения после обновления откроется главная.

## Файлы

- `index.html` — разметка.
- `styles.css` — оформление, мобильная сетка и переворот карточки; системные шрифты, UTF-8, учёт предпочтения уменьшенного движения.
- `script.js` — локальный словарь, логика заданий и сохранение выбора.
- `specs/001-nabory-slov.md` — требования и критерии готовности.
- `specs/002-rezultaty-prohozhdeniya.md` — правила подсчёта результатов и критерии готовности.
- `agents.md` — инструкции проекта.
- `tests/word-game.test.js` — проверки на встроенных средствах Node.js, без npm и зависимостей. Node.js нужен только для этих проверок, не для приложения.

## Как проверить

1. Откройте `index.html` двойным щелчком. При первом запуске видны шесть рубрик.
2. Выберите тему. Проверьте одну карточку, исходное слово и предложение на одном языке; IPA есть только для английского. Выбора языка вручную нет.
3. Убедитесь, что указан целевой язык и доступны три разных варианта. Выберите неправильный: карточка переворачивается, показывает правильный перевод и «Попробуй ещё раз».
4. Нажмите «Повторить»: ответ скрыт, доступны перемешанные варианты того же этапа. После правильного ответа сразу появляются варианты на втором языке под карточкой с подтверждением, без кнопки «Далее». Исходное слово и язык остаются прежними.
5. Проверьте ошибку и повтор на втором этапе. Только правильный ответ открывает «Следующее слово».
6. Пройдите десять понятий, убедитесь в отсутствии повторов и появлении «Набор пройден». Проверьте повтор набора и возврат к рубрикам.
7. На главной последняя выбранная тема выделена. Нажмите F5: сохранённый набор открывается с первого слова. Если браузер блокирует хранилище, приложение должно продолжать работать без сохранения.
8. Через инструменты разработчика задайте `localStorage.setItem('slovarium.category', 'unknown')` и обновите страницу: должна открыться главная. Очистка только выбора приложения: `localStorage.removeItem('slovarium.category')`.
9. Повторите проверку для всех тем и направлений перевода. Соседние исходные языки могут совпадать; распределение языков внутри десяти карточек не обязано быть равным.
10. На ширине 375px проверьте главную, обе стороны карточки и завершение: нет горизонтальной прокрутки, обрезанных надписей и перекрытий; все кнопки не меньше 44 × 44 CSS px. Проверьте казахские буквы и IPA.
11. Проверьте отсутствие запросов к внешним ресурсам в панели Network.

Проверка результатов прохождения:

1. Пройдите набор без ошибок: на экране завершения должны быть «Верно с первой попытки: 20 из 20» и «Ошибок: 0».
2. В новом прохождении ошибитесь дважды в одном задании и по одному разу ещё в двух заданиях. Завершите набор: должны быть «Верно с первой попытки: 17 из 20» и «Ошибок: 4».
3. Допустите четыре ошибки только в одном переводе слова; второй перевод и остальные задания выполните сразу правильно: результат 19 из 20, ошибок 4. Повторите для разных исходных языков и обоих этапов.
4. Проверьте сброс через «Повторить набор», возврат к рубрикам и выбор прежней или другой темы, в том числе после частичного прохождения с ошибками. Новое прохождение без ошибок должно дать 20 из 20 и 0 ошибок.
5. Нажмите F5 после ошибки и отдельно после завершения: сохранённая тема начинается с первого слова, прежний результат скрыт. Пройдите без ошибок и проверьте 20 из 20 и 0 ошибок.
6. На ширине 375px проверьте читаемость обеих строк результатов и доступность кнопок.

Автоматические проверки, если установлен Node.js:

```sh
node --check script.js
node --test tests/word-game.test.js
git diff --check
```

## Результаты проверки реализации

- Для результатов прохождения все 10 автоматических тестов прошли. Новые проверки покрывают независимый учёт двух переводов для всех исходных языков, повторные ошибки, примеры 17/20 и 4 ошибки, 19/20 и 4 ошибки, отсутствие ошибок и ошибки во всех заданиях; сброс при повторе и выборе рубрики; отображение итогов и новый сеанс после частичного и полного прохождения. Синтаксис JavaScript и `git diff --check` проверены.
- При проверке новой функции браузерное подключение снова сообщило `The browser access host is unavailable`. Реальное открытие двойным щелчком, F5, визуальный переворот, символы и вёрстка результатов на 375px остаются непроверенными. Восстановление рубрики и сброс результатов проверены автоматическими DOM-сценариями новых сеансов.

- Все 8 автоматических тестов прошли: 60 уникальных понятий и 180 заполненных вариантов; прохождение всех шести тем с ошибками на обоих этапах; запрет пропуска этапов; завершение и повтор; все направления переводов и оба порядка для каждого исходного языка; обработка хранилища; DOM-сценарии выбора, ответа, возврата и восстановления; локальные подключения и отсутствие сетевых API; автоматическое открытие второго этапа под подтверждением первого ответа, включая ошибку и повтор второго этапа.
- Проверки случайности используют воспроизводимый генератор; дополнительно проверены возможность соседних одинаковых языков и разные позиции правильного ответа. Они не требуют равного распределения в одном наборе.
- Словарь просмотрен, уточнены соответствия «машина — автокөлік» и «task — задание — тапсырма»; IPA приведена к британскому произношению. Независимая проверка преподавателем не выполнялась.
- Синтаксис `script.js` и отсутствие ошибок форматирования diff проверены.
- Браузерная проверка недоступна: инструмент сообщил `The browser access host is unavailable`. Поэтому реальный запуск двойным щелчком, F5 в браузере, визуальный переворот, отображение символов, фактические размеры элементов и отсутствие прокрутки на 375px остаются непроверенными. DOM-тесты проверяют события и содержимое, но не заменяют браузерную проверку вёрстки.

Проверка IPA: откройте задания с английским исходным словом и с переводом на английский; убедитесь, что IPA видна рядом с каждым английским вариантом и под правильным переводом после ответа. Для русского и казахского IPA не показывается.
