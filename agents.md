# AGENTS.md — Словариум

## О проекте
<Проект для детей для изучения трех языков одновременно - русскийого, английского и казахского языков.>
Файлы: index.html — разметка, styles.css — вид, script.js — логика.
Требования к функциям — в папке specs/. Описание для людей — в README.md.

## Правила
- Только HTML, CSS и JavaScript в этой папке. Без npm, библиотек и внешних ресурсов.
- Данные храни в браузере (localStorage). Ничего не отправляй в интернет.
- Интерфейс на русском языке, подписи короткие и понятные.
- Кнопки и поля не меньше 44px, страница работает на телефоне шириной 375px.
- Делай только то, о чём попросили. Работающие функции не ломай.
- После тестов, объязательно делать гит коммит
- пользователю предлагаются карточки со словами на английском, казахском или русском языке. пользователь выбирает и предложенных трех вариантов правильный перевод. каточка переварачивается и показывается правильный вариант. если изначально слово загадывалось на казахском то первым отгадывается перевод на английский а затем на русски. слова подаются в рандомном порядке. пока пользователь не выберет перевод слова на двух остальных языках отличном от языка представленного слова следующее задание не открывается. Казахские буквы (ә, ғ, қ, ң, ө, ұ, ү, һ, і) показывай без искажений

## Новая функция
- Каждую новую функцию начинай с файла specs/NNN-nazvanie.md. NNN — следующий номер: 001, 002, 003. Название — латиницей через дефис.
- Разделы файла: Для кого и зачем; Что должно быть; Примеры; Ограничения; Готово, когда.
- Пока я не написал «делай», код не пиши.
- Когда функция готова, обнови README.md: что умеет страница и как проверить.

## Как проверить
- Открыть index.html двойным щелчком.
- пользователь выбирает перевод слова из предложенных вариантов, далее карточка переварачивается и показывается правильный вариант перевода.
- После F5 данные на месте.
